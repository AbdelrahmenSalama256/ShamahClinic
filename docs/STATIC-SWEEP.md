# Static sweep: what the live site actually publishes

Task A of the WordPress integration: find out whether the content this repository still
carries as authored static copy exists anywhere on the live site, and wire whatever does.

The REST API alone does not show everything the live site renders — menus, floating
call buttons, widgets, theme footer blocks and shop chrome only exist in the HTML — so
the sweep crawled rendered pages, not just `/wp-json`.

## How it was searched

`scripts/wp-sweep.mjs` (added with this pass, GET only, concurrency 2, 300 ms between
requests, per-request timeout):

1. **Discover URLs** — `robots.txt`, every sitemap, plus internal links found while
   crawling (BFS, depth ≤ 2), for both `https://www.shamahclinics.com` and `/ar/`.
2. **Fetch each URL's rendered HTML** — 217 requests, 19.4 MB, 200 documents,
   193 returned HTTP 200 (7 aborted on timeout: `/ar/hero-image`, `/ar/sample-page`,
   `/checkout`, `/contact-2`, `/hero-image`, `/sample-page` and one duplicate — all
   WooCommerce/theme pages this site does not use). Output:
   `.tmp/sweep/manifest.json`, `.tmp/sweep/html/<sha1>.html`.
3. **Match text** — for every static item, its exact AR and EN phrases plus generic
   markers, searched across all crawled documents and all snapshot posts/pages
   (516 searched strings). Output: `.tmp/sweep/matches.json`, with the URL, CSS
   selector and quoted snippet of each hit.

Snapshot used: `data/wp/*.json` (92 EN posts + 92 AR posts, 27 pages, both languages).
The live crawl was run after the origin came back up on 2026-10-13; post coverage was
cross-checked: 92 live EN content slugs = 92 snapshot posts, so nothing is truncated.

**Theme/demo pages found and deliberately never wired** (Artday theme + WooCommerce
demo content, not the client's copy): `artist-slider`, `creative-slider`,
`parallax-image`, `3d-parallax-hero`, `slider-fullscreen`, `slider-fullwidth`,
`hero-image`, `sample-page`, `contact-2`, `shop-2`, `cart-2`, `checkout-2`,
`my-account-2`, `refund_returns`, and the `/faq` + `/privacy` pages quoted below.

## What this pass wired

- `src/lib/wp/home-prose.ts` (new) — parses the homepage prose rows: excludes the
  revslider, `/product/` and anchor rows and any row with more than one heading, drops
  button labels (`isButtonLabel`), captures `<br>`-separated lines, mirrors the row
  image, and zips EN↔AR by heading with the `arabicRatio()` guard.
- `getHomeIntro()` / `getHomeProseSections()` in `src/lib/wp/index.ts` — snapshot first,
  live fallback, never throws.
- Home band 1's introduction and `/about`'s two extra rows now come from WordPress.

Everything else above keeps its static copy with the negative-search evidence recorded
here, so the next person does not re-run this sweep to find out.
